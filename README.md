# 🌟 About The Project

Spotify Web Music Player is a sleek and modern music streaming web application inspired by Spotify's elegant UI and immersive user experience.

Built using pure HTML, CSS, and JavaScript, this project focuses on:

* 🎵 Smooth music playback
* ⚡ Fast performance
* 🎨 Modern UI/UX
* 📱 Fully responsive design
* 🌙 Dark aesthetic theme
* ✨ Smooth animations & transitions

This project was created to practice frontend development, UI/UX design, component architecture, and responsive web development.


# ✨ Features

## 🎶 Music Features

* ▶️ Play / Pause songs

# ⚡ Installation

## Clone the repository

```bash
git clone https://github.com/Kunalshengokar/Spotify-Web-Music-Player.git
```

## Navigate to the project folder

```bash
cd Spotify-Web-Music-Player
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```
